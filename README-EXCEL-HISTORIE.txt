Historie: Oktober 2007 bis September 2026
Importierte Buchungen: 16.322

Zuordnung der alten Excel-Kategorien:
- Nahrungs- und Haushaltsmittel -> Lebensmittel & Haushalt / Lebensmittel & Haushalt (historisch)
- Einrichtung/Baumarkt/Elektronik -> Einrichtung / Einrichtung / Baumarkt / Elektronik (historisch)
- Kleidung/Schuhe/Parfüm -> Bekleidung / Kleidung / Schuhe / Parfüm (historisch)
- Benzin/Fahrt-/Mietkosten -> Mobilität / Auto / Kraftstoff / Fahrtkosten (historisch)
- Nah-/Fernverkehr -> Mobilität / ÖPNV / Bahn (historisch)
- Versicherungen/Rente/Bank -> Versicherungen / Altersvorsorge / Finanzen / Versicherungen / Rente / Bank (historisch)
- Sonstige Zahlungen/Friseur/Strafe/Reparatur/Geschenke -> Sonstiges / Lifestyle / historische Sammelkategorie
- Miete+Strom -> Wohnen / Miete / Strom (historisch)
- Handy und Telefon -> Wohnen / Mobilfunk / Telefon (historisch)
- Vergnügen/Urlaub -> Freizeit / Vergnügen / Urlaub (historisch)
- Gesundheit/Arzt/Medikamente -> Gesundheit / Gesundheit / Arzt / Medikamente (historisch)
- Z -> Sonstiges / Lifestyle / Zigaretten
- Einkommen netto -> Einnahmen / Einkommen / Gehalt

Nicht als Einnahme/Ausgabe übernommen:
- Bar vom Konto abgehoben
- Einzahlung aufs Konto
- Einzahlung Kasse
Diese Positionen sind Konto-/Kassenumbuchungen und würden die Haushaltsauswertung sonst doppelt beeinflussen.

Hinweis: Formeln mit mehreren Teilbeträgen werden als Tages-/Kategoriesumme übernommen. Händler und einzelne Teilkäufe lassen sich daraus nicht sicher rekonstruieren.
